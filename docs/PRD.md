| 项 | 内容 |

## 1. 产品概述

### 1.1 背景

每次旅行会产生照片、交通票据、城市记忆，但这些内容散落在相册、备忘录、聊天记录里，事后很难按"我去过哪、怎么走的、当时什么样"串成一个整体。

### 1.2 产品定位

**个人旅行足迹可视化地图**：以 3D 地球为核心载体，展示旅行轨迹（飞机 / 高铁）、点亮到访城市，并以时间线串联日期与对应地点的照片。

### 1.3 目标用户

- **主要用户（唯一）**：产品所有者本人 —— 个人记录与回忆，无多用户、无社交。
- **次要受众**：被分享链接的亲友（只读浏览，P3 支持分享）。

### 1.4 核心价值

1. **记录**：城市、路线、日期、照片一处沉淀；
2. **回忆**：按时间重放每一段旅程（情绪价值是灵魂功能）；
3. **分享**：一个链接/一段录屏即可展示旅行足迹。

### 1.5 设计原则

| 原则 | 含义 |
|---|---|
| 数据只录一次 | 城市点亮由行程/到访记录自动推导，不重复维护 |
| 录入 ≤ 2 分钟 | 添加一次旅行 = 加一条数据 + 拖入几张照片；新增字段必须过审 |
| 视觉即内容 | 地球与轨迹的美感本身就是产品价值，宁可少功能不能丑 |
| 隐私默认 | 纯静态、本地数据，照片不上传第三方 |
| 渐进增强 | MVP 先跑通，回放、EXIF、编辑器分迭代叠加 |

## 3. 详细功能需求

### 3.1 主视图：3D 地球（P0）

**基础表现**

- 打开应用默认全屏加载 3D 球体地球（非 2D 平面地图）；
- 支持鼠标拖拽旋转、滚轮/触控板缩放；
- 深色太空背景（星空），地球带大气辉光边缘；
- 初始视角：斜俯视角度，自动缓慢自转；用户交互后暂停自转，静止 N 秒后恢复（建议 10s）。

**城市点亮机制**

| 状态 | 表现 |
|---|---|
| 已到访城市 | 发光脉冲圆点 + 城市名称浮标（hover/点击时常显） |
| 当前选中城市 | 圆点放大、光晕增强，地球相机自动飞行聚焦 |
| 未到访城市 | 不渲染任何标记（地图上不存在"未点亮的点"） |

- 城市坐标来自内置城市坐标表，用户只填城市名；
- 点的视觉权重按到访次数微调（去过多次的城市光晕略大）；
- **点击城市 → 弹出城市卡片**：
  - 城市名、首次/最近到访日期、到访次数；
  - 每次到访的日期与备注；
  - 该城市照片缩略图条，点击查看大图（lightbox）；
  - 关联行程高亮（卡片内列出涉及该城市的航段，点击聚焦对应轨迹）。

**任意位置点击反查地名（全球，P0）**

> 需求：点击地球任意一块区域，必须显示该区域的名称与范围（例：点击深圳 → 高亮深圳市并显示"深圳市"），不限于已点亮城市。

- 完全离线反查，无第三方 API、无网络依赖：
  - **中国境内**：精确到地级市/直辖市（370 个行政区域边界）；标签显示「深圳市　广东省 · 中国」；
  - **中国境外**：精确到国家（177 个国家，中文名）；标签显示国家名；
  - **海洋/无归属**：显示「海洋」+ 点击点经纬度坐标。
- 命中区域以琥珀色半透明多边形高亮（贴地拉伸，随球旋转），点击处显示玻璃拟态名称标签，标签随球转动、转到背面自动隐藏；
- 点击城市级区域相机平滑拉近；国家级保持远景；标签关闭按钮或再次点击他处切换；
- 边界数据由 `scripts/build-geo.mjs` 一次性构建，产物在 `public/geo/`（中国 594KB、国家 106KB，gzip 合计约 230KB），浏览器空闲时预取。
- 已点亮旅行城市与本功能相互独立：任意点都能查名，旅行城市另有发光点与卡片。

**轨迹线**

| 类型 | 视觉 | 几何 |
|---|---|---|
| ✈️ 飞机 flight | 浅色半透明**虚线**、明显抬升的高空弧线 | 地球大圆航线（great circle），弧顶高度按航程比例 |
| 🚄 高铁 train | **实线**、贴近地面的低弧折线 | 以经停城市为 waypoint 分段绘制，贴地或极低高度 |

- 每条轨迹绑定：出行日期、交通类型、备注（航班号/车次等）；
- Hover 轨迹：整条高亮提亮，显示 tooltip（日期 · 起→终 · 备注）；非相关轨迹降低透明度；
- **重复航线处理**：相同起终点的多条轨迹做微小弧度/侧向偏移，避免完全重叠成一条线；
- MVP 不做轨迹随时间显隐的"生长动画"，纳入 P1 回放。

### 3.2 顶部时间轴（P0）

采用**顶部横向胶片条（filmstrip）**布局：

```
┌──────────────────────────────────────────────────────────────┐
│  2025.05.01–05.05  杭州 · 五一出行            [ 大图 16:9 ]    │  ← 主图区
├──────────────────────────────────────────────────────────────┤
│ ●━━━●━━━━━━●━━━●━━━━━━━●━━━●                                  │
│ 京   杭      沪   苏      京   蓉                              │  ← 胶片节点
│ 4.30 5.1     5.3 5.3     5.5 6.10                             │
└──────────────────────────────────────────────────────────────┘
```

- 节点粒度 = 每一段行程（trip）/ 每次城市到访（visit），按日期排序；
- 每个节点：日期 + 城市名 + 照片缩略图；无照片的节点显示交通类型图标占位；
- 横向滚动/拖拽浏览；当前选中节点居中放大；
- **点击/拖动节点**：
  1. 地球相机平滑飞行到对应城市；
  2. 高亮本次行程轨迹，其余轨迹淡出；
  3. 顶部主图区切换为该地点代表照片 + 日期（区间）；
- 主图区为玻璃拟态半透明卡片，不遮挡地球主体；照片做缓慢 Ken Burns 缓动（P1）。

**两种浏览视角（MVP 提供切换）**

1. **时间流模式**：按时间顺序逐段浏览故事（默认）；
2. **全局模式**：取消选中，展示全部城市与全部轨迹，回到自转总览。

### 3.3 统计区（P0）

角落低调展示，点击可展开：

- 去过城市数、覆盖省级行政区/国家数；
- 飞行 X 段、高铁 X 段；
- 累计轨迹里程（大圆距离 + 段长求和，单位 km）；
- 首次出发行日期、最近一次出行日期。

### 3.4 旅行回放（P1，灵魂功能）

- 时间轴左侧播放键 ▶️：从最早行程按日期顺序自动播放；
- 飞机/高铁小图标沿当前轨迹从起点移动到终点，到达后城市点亮、主图照片切换，再进入下一段；
- 支持暂停、速度切换（0.5x / 1x / 2x）、进度拖动；
- 回放结束停在全局模式总览。

### 3.5 照片管理

- **MVP**：照片放 `public/photos/<visit-id>/`，在 visit 数据中按文件名引用；时间轴与卡片读取；lightbox 看大图；
- **P1**：构建/启动时用 `exifr` 读取 EXIF 拍摄时间，自动匹配行程日期与城市，生成"待确认归组"列表，用户确认即可，免手动建文件夹；
- **P2（v0.3）**：旅程封面拼图、地点篇章、沉浸式照片回忆舞台、精选/全部、自动播放与减少动态模式；
- 缩略图与原图分离，缩略图随时间轴懒加载，原图仅 lightbox 时请求；
- 照片支持可选一句话标注（caption）。

### 3.6 数据录入与编辑

- **MVP**：手工维护一份 `src/data/trips.json`（结构见第 4 节），照片按约定目录放入；
- **P3**：页面内表单编辑器（添加城市到访、添加行程、拖拽照片），数据存 localStorage，支持导出/导入 JSON 覆盖文件，彻底不碰手写 JSON。

## 4. 数据模型

一份 `trips.json` 为唯一数据源；城市点亮、轨迹、时间轴全部由它**自动推导**。

> v1.2 增补：数据模型新增一级对象 `Journey`，并为 `Trip` / `Visit` 增加 `journeyId`。`Visit` 只记录真实旅行目的地，常居城市由 `meta.homeCity` 独立点亮，不计入旅程目的地统计。详细目标结构见 [旅程阶段与照片回忆体验设计](./superpowers/specs/2026-10-21-journey-memory-experience-design.md)。

```json
{
  "meta": {
    "owner": "我的名字",
    "homeCity": "beijing",
    "version": 1
  },
  "cities": [
    { "id": "beijing", "name": "北京", "lat": 39.90, "lng": 116.40, "province": "北京", "country": "中国" },
    { "id": "hangzhou", "name": "杭州", "lat": 30.27, "lng": 120.15, "province": "浙江", "country": "中国" }
  ],
  "trips": [
    {
      "id": "t001",
      "date": "2025-05-01",
      "type": "flight",
      "from": "beijing",
      "to": "hangzhou",
      "waypoints": [],
      "note": "CA1234"
    },
    {
      "id": "t002",
      "date": "2025-05-03",
      "type": "train",
      "from": "hangzhou",
      "to": "shanghai",
      "waypoints": ["jiaxing"],
      "note": "G7558"
    }
  ],
  "visits": [
    {
      "id": "v001",
      "city": "hangzhou",
      "arriveDate": "2025-05-01",
      "leaveDate": "2025-05-03",
      "note": "五一西湖行",
      "photos": [
        { "file": "01.jpg", "caption": "断桥残雪" },
        { "file": "02.jpg", "caption": "" }
      ]
    }
  ]
}
```

**推导规则**

- 出现在任意 `visit.city` 中的城市 → 点亮；
- 每条 `trip` 渲染一条轨迹，`from`/`to`/`waypoints` 引用 cities 的 id；
- 时间轴节点 = visits 与 trips 按日期合并排序；
- 照片通过 visit id 定位目录：`photos/<visit-id>/<file>`；
- 里程：flight 取起终点大圆距离；train 取各段大圆距离之和（近似值，仅展示用）。

**校验要求（MVP 提供启动时校验脚本/控制台报错）**

- city id / from / to / waypoints 引用必须存在；
- 日期合法、arriveDate ≤ leaveDate；
- 照片文件实际存在；
- id 不重复。

## 5. 页面布局与交互

### 5.1 布局

```
┌───────────────────────────────────────────────────────────┐
│  左上角：标题/Logo            右上角：统计 | 模式切换 | 设置 │
│                                                           │
│              顶部主图区（玻璃卡片，靠右/靠上，可收起）          │
│                                                           │
│                    3D 地球全屏区域                          │
│              · 城市脉冲点 · 弧线轨迹                        │
│                                                           │
│  城市卡片（点击城市后浮现，地球左侧或定位点旁）                  │
│                                                           │
├───────────────────────────────────────────────────────────┤
│  顶部/底部时间轴胶片条（悬浮半透明，自动隐藏可选）               │
└───────────────────────────────────────────────────────────┘
```

### 5.2 关键交互流

1. **首次进入**：加载地球 → 自动缓慢自转 → 展示全部点亮城市与轨迹 → 3 秒后主图区提示"点击时间轴开始你的旅程"。
2. **时间轴浏览**：点击节点 → 相机飞行聚焦 → 轨迹高亮 → 照片切换；再次点击当前节点或点击空白 → 回全局模式。
3. **城市探索**：点击城市点 → 城市卡片 → 点照片进 lightbox（Esc/点击遮罩退出）→ 点关联行程跳转轨迹视角。
4. **轨迹探索**：hover 弧线 → tooltip + 高亮；点击 → 锁定该段视角并在时间轴定位对应节点。

### 5.3 视觉方向

- 基调：深色太空 + 冷色地球，发光元素克制使用；
- 飞机轨迹：浅蓝白虚线半透明；高铁轨迹：暖色（琥珀/金）实线；
- 城市点：暖白/金色脉冲；选中态青色或品牌色；
- UI 层：玻璃拟态（毛玻璃 + 1px 高光描边），中文无衬线（系统字体栈）；
- 动效时长统一在 200–600ms，相机飞行用 ease 缓动，避免线性机械感。

## 6. 技术方案

| 层 | 选型 | 理由 |
|---|---|---|
| 构建 | Vite + React + TypeScript | 轻量、生态成熟 |
| 样式 | Tailwind CSS | 快速搭建玻璃拟态 UI |
| 地球 | **react-globe.gl**（three.js 封装） | 大圆弧线、贴地路径、HTML 标记开箱即用；Cesium 过重，裸 three.js 成本高 |
| 地图纹理 | 在线暗色地球纹理（night earth）或下载到本地 | 本地化为佳，避免外链失效 |
| 几何 | d3-geo（大圆插值、`geoContains` 球面反查）/ globe.gl arcs | 弧线采样点、点在多边形内 |
| 行政边界 | DataV 中国地级市 + world-atlas 110m 国家，topojson 离线产物（`pnpm build:geo`） | 点击反查地名，无网络依赖 |
| 照片 EXIF | exifr（P1） | 体积小、浏览器端解析 |
| 数据 | 静态 JSON + 静态图片目录 | 无后端、零运维、隐私安全 |
| 部署（P3） | Vercel / GitHub Pages 纯静态 | 一个链接分享 |

**性能要求**

- 首屏可交互 < 3s（本地示例数据规模下）；
- 照片缩略图懒加载，原图按需；
- 轨迹/城市数量 ≤ 数百规模时保持 60fps（MVP 数据量远小于此）；
- 缩放级别低时城市名浮标隐藏，避免文字密集（聚合仍不做，只做显隐）。

**浏览器支持**：最新版 Chrome / Edge / Safari（桌面端）。

## 8. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 录入成本高，长期弃更 | 产品失去数据，名存实亡 | MVP 录入 ≤2 分钟；P1 EXIF 自动归组；P3 表单编辑器；字段极简 |
| 高铁"真实路网"开发陷阱 | 成本高、观感收益极低 | 明确否决；用经停点贴地折线表达，靠高度差区分交通方式 |
| 照片增多后加载慢 | 页面卡顿 | 缩略图/原图分离 + 懒加载；P1 增加构建期缩略图生成 |
| 重复航线重叠成一条线 | 行程次数信息丢失 | 同起终点轨迹做弧度/侧向微偏移 |
| 在线地图/纹理外链失效 | 地球变灰 | 纹理资源下载到仓库本地化 |
| 视觉做成"数据大屏"而非纪念册 | 情绪价值缺失 | P1 回放 + Ken Burns 照片动效优先于更多图表 |

---

## 9. 里程碑建议

- **v0.1 MVP**：地球 + 城市 + 两类轨迹 + 时间轴 + JSON 数据 + 示例行程
- **v0.2 回忆增强**：旅行回放、EXIF 归组、缩略图管线、照片缓动
- **v0.3 旅程阶段与照片回忆**：旅程层级、范围联动、照片回忆舞台、旅程内回放
- **v0.4 可维护/可分享**：表单编辑器（localStorage + 导入导出）、静态部署、截图/GIF 导出

## 10. v1.2 产品升级：旅程阶段与照片回忆

完整设计见 [旅程阶段与照片回忆体验设计](./superpowers/specs/2026-10-21-journey-memory-experience-design.md)。

### 10.1 核心变化

- 产品层级调整为“旅行档案 → 一段旅程 → 地点篇章 → 照片回忆”；
- 新增 `Journey` 一级对象，交通段与到访通过 `journeyId` 归属旅程；
- 常居城市以独立样式点亮，不作为旅行到访或旅程地点篇章；
- 地球、轨迹、地点卡片、时间轴、统计和回放全部支持“全部旅行 / 当前旅程”两种范围；
- 回放默认以当前旅程为单位，不再从全部历史中连续播放；
- 照片体验从 Lightbox 升级为沉浸式回忆舞台，支持精选、全部、自动播放、键盘和减少动态模式；
- 增加光门转场、章节卡、路线流光、载具拖尾、城市到达波纹和回忆星图等电影化特效；
- 提供静谧 / 电影感 / 沉浸三档动效强度，默认电影感；减少动态模式始终优先；
- 照片资产拆分为 160px / 640px / 1600px / 原图四级，小卡不加载大图，原图只在缩放时请求；
- 旅行档案按年份组织并优先展示最近旅程；桌面端提供完整体验，390px 宽度下保证核心浏览可用；
- 视觉方向确定为“夜航星图 × 私人旅行电影”，保留星图导航层，并增加暖色照片回忆层。

### 10.2 必须满足的边界

- 同一城市在不同旅程中的到访与照片不得混合；
- 常居城市不得作为普通旅行到访进入地点篇章或目的地统计；
- 旅程、交通段、到访和封面照片的引用必须通过数据校验；
- 每段旅程可包含数百张照片，原图不得随页面初始化批量加载；
- 照片“精选”由数据文件策展，无精选时隐藏精选入口；
- 切换旅程时必须清理旧选中对象、回放和照片舞台状态；
- 同一时刻最多一个主运动，并可叠加两个内容动画；低帧率时自动降低特效等级；
- 现有地球交互、地名反查、轨迹 hover、EXIF 归组和缩略图管线继续保留；
- 示例日期只用于说明，不作为产品或代码中的固定数据。

### 10.3 v0.3 实现状态（2026-10-22）

- 旅行档案、旅程护照、地点篇章、照片回忆舞台和回忆星图已按旅程范围落地；
- 默认电影感，支持静谧 / 电影感 / 沉浸三档切换与本地持久化，系统减少动态始终优先；
- 页面唤醒、路线生长、城市点亮、路线流光、载具拖尾、光门、章节卡和星图景深已实现；
- 390px 宽度下保证档案、旅程、地点篇章、回忆舞台与移动端瀑布流的核心浏览可用；
- 照片继续使用 `blur / thumb-sm / thumb-md / preview` 派生资产，原图仅在缩放时按需请求；
- 页面后台暂停装饰动画，低帧率连续触发时自动降档；Gate C 的浏览器验收与测量限制记录在实施计划中。
