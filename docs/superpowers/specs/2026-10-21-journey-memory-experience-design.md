> 体验主张：把地图当作星图，把旅程当作章节，把照片当作可以停留的光。
>
> 用户提供的日期只用于说明“一段旅行”的形态，不作为固定业务数据写入产品。

---

## 1. 设计摘要

产品从“行程与地点浏览器”升级为“旅程阶段式的个人旅行回忆册”：

```text
旅行档案
└── 一段旅程
    ├── 城市 / 地点篇章
    │   └── 照片回忆
    └── 本段旅程回放
```

核心变化：

1. “旅程”成为一级对象，轨迹、到访、照片、统计和回放先归属旅程，再在旅程内展开。
2. 同一城市在不同旅程中的到访、笔记和照片完全隔离。
3. 旅行档案按年份组织，默认优先展示最近旅程。
4. 照片体验从 Lightbox 升级为全屏回忆舞台，形成“星图 → 章节 → 照片”的连续观影感。
5. 常居城市只点亮，不伪装成旅行到访；旅行统计与生活轨迹明确分开。
6. 每段旅程可承载数百张照片，通过分级图片资产、渐进加载和虚拟化保持流畅。
7. 桌面端提供完整体验，移动端至少保证旅程浏览和照片回忆可用。
8. 加入完整动画编排、电影化照片转场和回忆星图，并提供三档动效强度与自动降级。

---

## 2. 问题与设计机会

现有数据结构把 `Trip` 与 `Visit` 平铺在全局时间轴上，没有“这次旅行”这个概念。由此产生四个问题：

- 两段旅行中的同一城市会被错误合并；
- 回放从全部历史连续开始，无法只重温一段经历；
- 主图只取第一张照片，大量照片缺少叙事层级；
- 常住城市的日常停留与真实旅行目的地混在一起。

设计机会不是增加更多图表，而是建立一套“回忆语法”：

- 旅程负责建立边界；
- 地点负责建立章节；
- 照片负责建立停留和情绪；
- 动效负责连接空间与时间；
- 声音、颗粒、光线与文字只用于增强记忆，不喧宾夺主。

---

## 3. 目标与非目标

### 3.1 目标

1. 以旅程组织一段时间内的多个地点，而不是平铺交通段和到访节点。
2. 同一城市跨旅程出现时，数据、照片和统计彼此隔离。
3. 每段旅程拥有独立标题、题记、封面、路线、统计和回放。
4. 每个地点提供地点封面、回忆入口和完整相册。
5. 收藏照片通过数据策展形成“精选回忆”，没有精选时自动隐藏该入口。
6. 支持每段旅程数百张照片，首屏不加载原图。
7. 从地图进入照片回忆时保持空间连续性，形成沉浸但可返回的体验。
8. 所有主动画遵循减少动态设置，桌面与移动端均能完成核心操作。

### 3.2 非目标

- 不增加用户系统、云端同步、社交互动或多人协作。
- 不重做完整页面内编辑器；精选、题记和封面继续通过数据文件策划。
- 不做完整的移动端专项设计，但必须提供 390px 宽度下的可用布局。
- 不引入 AI 自动写游记、自动选片或自动配乐。
- 不改动地名反查、行政边界和中国境内外判断逻辑。
- 不在本阶段实现“全部旅行蒙太奇”。

## 4. 体验原则

| 原则 | 设计要求 |
|---|---|
| 旅程优先 | 默认入口是旅程，不直接暴露全部交通和到访节点 |
| 范围明确 | 用户始终知道自己在看“旅行档案”还是“当前旅程” |
| 回忆重于数据 | 先呈现标题、照片、题记和路线，再把统计放进第二层 |
| 照片有节奏 | 封面负责吸引，精选负责叙事，全部负责完整回看 |
| 一镜到底 | 场景切换使用连续镜头语言，不混用多种夸张转场 |
| 动效克制 | 同一时刻只保留一个主运动，避免地球、卡片和照片同时抢注意力 |
| 大量也从容 | 小图用于导航，中图用于浏览，大图用于沉浸，原图只用于放大 |
| 常住不等于旅行 | 常居城市单独点亮，不进入旅程统计与地点篇章 |
| 隐私本地 | 照片解析、缩略图和浏览都在本地完成，不上传第三方 |

## 5. 信息架构

### 5.1 四层结构

1. **旅行档案**：展示全部旅程，是默认首页。
2. **旅程视图**：展示一段旅程的完整路线、地点、叙事和统计。
3. **地点篇章**：展示当前旅程中的某个城市或地点。
4. **照片回忆**：进入沉浸式照片舞台，浏览当前地点或当前旅程的照片。

### 5.2 主导航

- 左上角：产品标题与面包屑。
- 右上角：管理入口、全局统计、动效强度与显示设置。
- 中央：3D 地球与路线。
- 右侧：当前旅程护照或地点摘要。
- 底部：当前层级的旅程月台或地点章节轴。
- 低频的 EXIF 照片归组收进“管理”面板，不长期占据主界面。

### 5.3 时间方向

- 旅行档案按旅程结束日期倒序，最近旅程优先。
- 同一旅程内部严格按日期正序，形成从出发到归程的叙事。
- 同一年的旅程归入同一个年份段。
- 超过 6 段旅程时，底部只展示最近 3 段，其余进入“全部旅程”抽屉。

## 6. 状态与导航规则

### 6.1 状态分层

“当前旅程”“当前选中对象”和“照片舞台”必须是三个独立状态：

```text
JourneyScope
  ├── archive
  └── journey(journeyId)

Selection
  ├── none
  ├── visit(visitId)
  ├── trip(tripId)
  └── city(cityId)

MemoryOverlay
  ├── closed
  └── open({
        source,
        mode: 'stage' | 'constellation',
        photoIndex
      })
```

- `JourneyScope` 决定地球、轨迹、地点卡片、章节轴和统计的数据范围。
- `Selection` 只描述当前聚焦的到访、交通段或城市。
- `MemoryOverlay` 独立管理照片舞台，不改变底层旅程范围。
- 回放状态必须在切换范围时终止，不允许跨旅程继续播放。

### 6.2 状态切换矩阵

| 操作 | JourneyScope | Selection | MemoryOverlay | 其他动作 |
|---|---|---|---|---|
| 打开旅程 | `journey(id)` | `none` | `closed` | 终止回放、关闭地点卡片、清除反查区域 |
| 切换旅程 | 新 `journey(id)` | `none` | `closed` | 终止旧回放与相机动画 |
| 返回旅行档案 | `archive` | `none` | `closed` | 终止回放、关闭卡片、清空面包屑子级 |
| 打开地点 | 不变 | `city(id)` | `closed` | 聚焦城市、更新地点篇章 |
| 打开交通段 | 不变 | `trip(id)` | `closed` | 高亮轨迹、播放一次载具动效 |
| 打开照片回忆 | 不变 | 保持 | `open(stage, source, index)` | 锁定焦点、记录返回焦点 |
| 打开回忆星图 | 不变 | 保持 | `open(constellation, journeyId, 0)` | 暂停地球装饰动画、记录返回焦点 |
| 关闭照片回忆 | 不变 | 保持 | `closed` | 焦点返回照片入口 |
| 退出回放 | 不变 | 保持最后选中对象 | `closed` | 回到当前旅程视图，不强制回档案 |

### 6.3 返回顺序

```text
照片回忆 → 地点篇章 → 旅程视图 → 旅行档案
```

- Esc 或浏览器返回只向上退一层。
- 面包屑任意一级可直接返回。
- 任何返回动作都必须关闭不再适用的浮层和播放状态。

## 7. 旅行档案

### 7.1 地球与常居城市

- 旅行档案展示全部旅程的城市与轨迹。
- `meta.homeCity` 始终以“常居”样式点亮，使用空心光点或双环标识，与旅行城市区分。
- 常居城市不计入“旅行目的地数量”，不生成地点篇章，也不参与旅程回放的到达停留。
- 返回常居城市的交通段仍属于对应旅程，因为它是旅程的归程。

### 7.2 旅程月台

底部以“旅程月台”替代全部事件胶片条：

- 默认展示最近 3 段旅程，按结束日期倒序；
- 每张卡显示 3 张照片的封面拼图；
- 展示标题、日期范围、题记、地点数、照片数和主要交通方式；
- 最近一段旅程使用更宽的主卡，其余使用紧凑卡；
- “全部旅程”按钮打开按年份分组的档案抽屉。

### 7.3 单段旅程卡

```text
┌─────────────────────────────────────┐
│  [照片] [照片]     2026.09.13–09.23 │
│  [照片]            北疆的秋光       │
│                                     │
│  7 个地点 · 286 张照片 · 2 段交通   │
│  从乌鲁木齐向北，追逐一场迟到的秋天  │
└─────────────────────────────────────┘
```

封面优先使用 `coverPhotos`。缺少封面时，使用路线弧线、日期和辅助色生成星图风格封面。

### 7.4 初始文案

引导文案使用“选择一段旅程，重新走一遍”，不要求用户先理解时间轴、节点或轨迹。

## 8. 旅程视图

### 8.1 地图范围

- 默认只显示当前旅程的轨迹与城市。
- 其他旅程默认不可见，避免范围混淆。
- 可通过旅程护照中的“显示其他旅程”开关，将其他旅程显示为不透明度 6%–10% 的星尘层。
- 星尘层不可点击、不显示城市名称、不参与统计，只提供旅行积累感。
- 进入另一段旅程时开关重置为关闭；回放期间隐藏星尘层。

### 8.2 旅程护照

右侧展示当前旅程护照：

- 3–5 张照片组成非对称拼图；
- 标题、日期范围、题记和简介；
- 地点数、照片数、交通段数和里程；
- “开始旅程回放”按钮；
- “显示其他旅程”开关；
- “全部照片”入口。

### 8.3 地点章节轴

底部切换为当前旅程的章节轴：

- 起点；
- 交通段；
- 地点到访；
- 下一段交通；
- 终点。

每个地点节点显示日期、地点名和一张 160px 缩略图。没有照片的地点使用路线色块和地名首字占位。

### 8.4 动效编排

进入旅程时依次发生：

1. 镜头飞向整段路线范围；
2. 轨迹从起点向终点生长；
3. 地点光点按时间顺序依次亮起；
4. 常居城市保持独立的空心双环状态；
5. 旅程护照从右侧浮入；
6. 底部章节轴替换为当前旅程内容。

若旅程只有一个地点或没有交通段，镜头直接聚焦该地点，跳过路线生长。

## 9. 地点篇章

### 9.1 数据范围

- `JourneyScope.journey` 下，城市卡片只读取当前旅程内的到访。
- 旅行档案级别的城市卡片可以汇总多次到访，但必须按旅程分组。
- 常居城市不显示普通“旅行到访”内容。

### 9.2 卡片结构

地点篇章包含：

- 地点名称、所属区域；
- 当前旅程中的到访日期；
- 一句地点记忆，优先使用 `Visit.note`；
- 地点照片数量；
- 一张主图和最多 4 张辅图组成的非对称拼图；
- “进入照片回忆”按钮；
- 当前旅程内相关交通段。

### 9.3 记忆层级

- 主图负责建立“那天的第一眼”；
- 辅图负责呈现同行、街景、食物和细节；
- 文字只保留一句记忆，不在卡片中堆叠长段落；
- “进入照片回忆”是唯一主动作，交通段入口保持次级。

### 9.4 空状态

- 没有照片：显示星图纹理和地名字标，禁用照片回忆按钮；
- 只有一张照片：直接进入单图舞台，不显示胶片条和自动播放；
- 同城多次到访：按日期分成各自章节，不合并成一段连续停留。

## 10. 照片回忆

### 10.1 体验结构

照片回忆使用全屏舞台，而不是继续扩展现有 Lightbox：

```text
┌────────────────────────────────────────────┐
│ 关闭                              日期 · 地点 │
│                                            │
│              [主照片 / 适度留白]             │
│                                            │
│  一句话说明                                │
│  ─────────────── 当前进度 ───────────────   │
│  [缩略图] [缩略图] [当前] [缩略图] [缩略图]  │
└────────────────────────────────────────────┘
```

- 地球退到背景，降低亮度并提高模糊，不直接消失；
- 主照片居中，使用暖色光晕、轻胶片颗粒和克制景深；
- 说明文字在主图后 120ms 出现；
- 底部缩略胶片条最后出现；
- 每进入新的日期或地点，插入 1 秒章节标题卡，例如“9 月 16 日 · 喀纳斯”。

### 10.2 浏览模式

- **精选**：只显示 `featured: true` 的照片；
- **全部**：按 `takenAt` 升序，缺少拍摄时间时沿用数组顺序；
- 没有精选照片时隐藏“精选”切换，不显示空视图；
- 所有照片均可返回地点篇章，不丢失当前日期和照片位置。

### 10.3 控制

- 左右切换；
- Esc 关闭；
- 播放 / 暂停自动回忆；
- 0.5x / 1x / 2x；
- 进度条；
- 缩放查看；
- 键盘方向键；
- 触屏左右滑动；
- “精选 / 全部”切换。

### 10.4 自动回忆

- 默认每张照片停留 5 秒；
- 切换使用 700ms 交叉淡化与 1.015 倍轻微推近；
- 页面进入后台时自动暂停；
- 用户拖动进度后保持暂停；
- 播放结束停留在最后一张，并显示“旅程会继续”类收束文案；
- 减少动态模式下不自动播放。

### 10.5 回忆感元素

- 照片入场时从轻微模糊过渡到清晰；
- 使用一次低强度柔光扫过，不循环闪烁；
- 背景星点只在照片切换时缓慢漂移；
- 颗粒纹理固定，不使用视频或持续噪声动画；
- 日期、地点和说明使用更温暖的文字层；
- 动效的目标是“凝神”，不是“炫技”。

### 10.6 回忆星图

“回忆星图”是旅程级照片的第二种浏览方式：

- 从旅程护照的“全部照片”打开，选择“回忆星图”视图；
- 以当前旅程路线为骨架，将地点照片簇散布在对应的城市节点周围；
- 照片按日期由远到近分层，旧照片更暗、更远，最近照片更亮、更近；
- 鼠标移动时产生 2–6px 的景深视差，卡片不持续漂浮；
- 点击任意照片，卡片从星图位置飞入照片舞台中心；
- 照片舞台关闭后，返回星图时保持缩放与滚动位置；
- 星图只加载当前视口内的 640px 缩略图，远离视口的照片不挂载原图；
- 390px 宽度下降级为按日期分组的瀑布流，不运行 3D 视差。

回忆星图用于制造“整段旅行在眼前铺开”的惊喜感；线性照片回忆仍负责完整叙事，两者互补。

## 11. 数据模型

### 11.1 旅程

```ts
type JourneyTheme = 'amber' | 'cyan' | 'sage' | 'rose'

interface Journey {
  id: string
  title: string
  startDate: string
  endDate: string
  epigraph?: string
  summary?: string
  theme: JourneyTheme
  coverPhotos: Array<{
    visitId: string
    file: string
  }>
}
```

约束：

- `startDate <= endDate`；
- `coverPhotos` 为 0–5 张，最多 5 张，引用真实照片；
- 没有 `coverPhotos` 时使用路线与主题色生成回退封面；
- `theme` 使用受控枚举，不接受任意色值；
- 日期来自真实数据，示例日期不写死在组件或文案中。

### 11.2 行程与到访

```ts
interface Trip {
  // 现有字段保持不变
  journeyId: string
}

interface Visit {
  // 现有字段保持不变
  journeyId: string
}
```

- 每段 `Trip` 必须属于一段旅程，包括出发、经停和归程。
- `Visit` 只记录真实旅行中的目的地停留。
- 常居城市的日常停留不创建 `Visit`，由 `meta.homeCity` 负责点亮。
- 轨迹、点亮城市和统计继续由记录推导，不重复保存派生数据。

### 11.3 照片

```ts
interface Photo {
  file: string
  caption?: string
  takenAt?: string
  featured?: boolean
  focalPoint?: {
    x: number
    y: number
  }
}
```

- `takenAt` 使用带时区偏移的 ISO 8601 字符串；
- 无时区信息时保留本地墙钟时间，并在排序时沿用数组顺序；
- `featured` 由数据文件手工策划，v0.3 不提供收藏写入界面；
- `focalPoint` 为 0–1 的归一化坐标；
- 图片宽高、多级缩略图和占位图由构建管线派生。

### 11.4 顶层结构

```ts
interface TravelData {
  meta: {
    owner: string
    homeCity: string
    version: 2
  }
  cities: City[]
  journeys: Journey[]
  trips: Trip[]
  visits: Visit[]
}
```

### 11.5 迁移规则

1. 备份原始 `trips.json`，不删除任何照片文件；
2. 为已有真实旅行创建旅程；
3. 将常居城市中表示“日常生活”的 `Visit` 从旅程数据中移除或标记为非旅程记录；
4. 为旅行交通段与目的地到访补 `journeyId`；
5. 为每段旅程设置标题、主题和 0–5 张封面；
6. 将数据版本提升为 2；
7. 更新校验与派生逻辑后替换示例数据。

### 11.6 校验规则

- 旅程 id 唯一，起止日期合法；
- `Trip.journeyId` 与 `Visit.journeyId` 必须存在；
- 交通与到访日期必须落在所属旅程日期范围内；
- 每条 `Trip` / `Visit` 只能关联一段旅程；
- 封面照片必须能解析到真实的到访与文件；
- `Visit.city === meta.homeCity` 时必须给出明确警告，不允许进入旅程地点篇章；
- 缺少精选照片不视为错误；
- 缺少封面照片不视为错误，使用生成式回退封面。

## 12. 统计规则

- 旅行档案统计旅行目的地数量，不把常居城市算作目的地；
- 常居城市单独显示为“常居地”；
- 当前旅程统计只计算该旅程内的交通、地点、里程和照片；
- 同一城市跨旅程不合并到旅程统计；
- 全局统计可以合并同一城市，但必须按旅程分组展示；
- 照片数按有效照片记录计算，缺图文件在开发模式下报错。

## 13. 视觉系统

### 13.1 视觉方向

“夜航星图 × 私人旅行电影”：

- 导航层是冷色、理性、精确的星图；
- 回忆层是暖色、柔软、带颗粒的私人影像；
- 进入照片回忆时，冷色地图逐渐退后，暖色记忆逐渐占据主画面。

### 13.2 色彩

| 用途 | 建议值 | 说明 |
|---|---|---|
| 深夜背景 | `#050811` | 保留当前太空基底 |
| 星图青色 | `#67e8f9` | 导航、轨迹、焦点状态 |
| 地点琥珀 | `#fbbf24` | 城市、日期、旅程强调 |
| 回忆暖白 | `#f5ead8` | 照片舞台文字与柔光 |
| 胶片灰 | `rgba(255,255,255,.14)` | 分隔线、边框、胶片齿孔 |

旅程主题色仅使用受控枚举，不覆盖导航色和状态色。

### 13.3 字体

- 界面文字优先使用本地系统中的中文无衬线字体；
- 旅程标题使用宋体类衬线字体栈，优先系统中文字体；
- 仅在固定品牌文字需要时加载极小的本地字体子集；
- 日期与坐标使用等宽字体；
- 不加载数 MB 的完整中文 Web Font。

### 13.4 材质

- 地图层：玻璃拟态、细描边、轻噪点；
- 旅程卡：深色玻璃上叠加照片内部光晕；
- 回忆层：暖色纸张感与轻胶片颗粒；
- 星尘层：只用于其他旅程和路线微光；
- 禁止爆炸粒子、烟花和满屏漂浮图标。

### 13.5 动效令牌

| 类型 | 时长 | 用途 |
|---|---:|---|
| 即时反馈 | 160ms | 按钮、hover、焦点 |
| 面板切换 | 280ms | 面包屑、卡片、详情面板 |
| 照片转场 | 700ms | 回忆舞台主图切换 |
| 章节切换 | 800–1000ms | 日期卡、颗粒闪断、照片重组 |
| 光门转场 | 700–1000ms | 进入或退出照片回忆 |
| 路线生长 | 900ms | 进入旅程或开始回放 |
| 镜头飞行 | 650–900ms | 城市与旅程聚焦 |
| 环境漂移 | 12–18s | 星点、星尘层的低速循环 |

统一使用 `transform`、`opacity` 和轻度 `filter`，避免动画化大面积布局属性。

缓动约定：

- 进入与展开：`cubic-bezier(0.16, 1, 0.3, 1)`；
- 退出与收起：`cubic-bezier(0.4, 0, 1, 1)`；
- 环境漂移：`ease-in-out`；
- 载具与流光：以回放或路线进度为时钟，不使用独立无限动画；
- 快速连续操作时优先使用 180–240ms 的降级转场。

## 14. 动画与特效系统

### 14.1 设计目标

增加动画和特效的目标是让页面“有生命”，而不是让所有元素持续运动：

- 页面开启时有一次完整的视觉唤醒；
- 旅程切换时有明确的空间运动；
- 照片切换时有类似电影的镜头变化；
- 页面静止时保留极轻的空气感；
- 同一时刻最多一个场景或转场主运动，并叠加最多两个内容层小动画；
- 所有特效都能被关闭、降级或由系统减少动态接管。

### 14.2 动画层级

| 层级 | 作用 | 示例 | 上限 |
|---|---|---|---|
| 场景层 | 表达空间关系 | 地球镜头飞行、路线生长 | 同一时刻 1 个 |
| 转场层 | 表达层级变化 | 照片舞台开启、章节标题卡 | 同一时刻 1 个 |
| 内容层 | 表达信息变化 | 照片推近、卡片入场、文字浮现 | 最多 2 个 |
| 环境层 | 提供空气感 | 星点漂移、微尘、路线流光 | 持续低强度 |
| 反馈层 | 表达操作结果 | hover、按压、焦点光环 | 立即响应 |

### 14.3 动效强度

右上角提供三档动效强度，默认“电影感”：

| 档位 | 体验 | 主要差异 |
|---|---|---|
| 静谧 | 快速、克制 | 无视差、无路线流光、照片短交叉淡化 |
| 电影感 | 默认完整体验 | 路线生长、镜头转场、柔光扫过、章节卡 |
| 沉浸 | 更强空间层次 | 封面 3D 视差、星点深度漂移、回忆星图景深 |

规则：

- 动效强度保存于 `localStorage`，只影响表现，不改变数据；
- `prefers-reduced-motion: reduce` 强制使用静谧模式；
- 触屏设备默认不启用鼠标视差；
- 用户切换档位时立即生效，不重新加载页面。

### 14.4 总编排表

| 场景 | 动画与特效 | 时长 |
|---|---|---:|
| 首次进入 | 星点由远及近、标题字距收拢、旅程卡错峰上浮 | 900–1200ms |
| 档案静止 | 星点缓慢漂移；路线流光每 7–9 秒经过一次 | 持续低强度 |
| 悬停旅程卡 | 封面三层视差、边框光沿边移动 | 180–320ms |
| 打开旅程 | 镜头飞行、路线生长、地点依次亮起、护照展开 | 900–1400ms |
| 打开地点 | 轨迹降亮、城市波纹、卡片浮入、主图显影 | 650–900ms |
| 打开照片回忆 | 地图退后、光门展开、主图显影、胶片条滑入 | 700–1000ms |
| 照片切换 | 方向感交叉淡化、轻微位移、柔光扫过 | 420–700ms |
| 章节切换 | 日期卡分屏入场、颗粒闪断、照片重组 | 800–1000ms |
| 打开回忆星图 | 地点照片簇依次点亮、卡片深度展开 | 900ms |
| 旅程回放 | 载具彗尾、城市点亮波纹、照片卡片显影 | 由回放时钟驱动 |
| 返回上级 | 当前层先行退后，背景地图恢复清晰 | 280–420ms |

### 14.5 首次进入与旅行档案

首次进入不阻塞数据加载，视觉效果在页面可用后叠加：

1. 星点从 0.3 透明度渐亮，并做一次 6px 的深度位移；
2. 标题字距从 0.4em 收拢到 0.26em；
3. 地球从 1.03 倍缩放回到正常尺度；
4. 旅程卡以 70ms 间隔错峰上浮；
5. 最近旅程的主卡最后出现，并获得一次 600ms 的光边描亮。

旅行卡 hover：

- 三层照片分别产生 1–3px 不同方向位移；
- 容器最大旋转 2°，避免廉价 3D 倾斜；
- 边框高光沿卡片边缘移动一次；
- 移动端不启用倾斜，只保留轻微亮度变化。

档案静止时：

- 星点以不同速度做极缓慢横向漂移；
- 路线每 7–9 秒出现一次 400ms 的流光脉冲；
- 流光只沿当前路线前进，不从屏幕边缘扫过；
- 页面失焦或处于后台时暂停。

### 14.6 旅程展开

打开旅程按以下顺序执行：

1. 镜头飞向路线范围，使用先快后慢的 `ease-out-expo`；
2. 路线从起点向终点生长，前端带 4–8px 的发光拖尾；
3. 城市光点按日期依次亮起，间隔 60–90ms；
4. 每个城市点亮时出现一次扩散波纹，波纹不循环；
5. 常居城市保持空心双环，只做一次轻微呼吸；
6. 旅程护照从右侧以 3D 翻页方式展开；
7. 章节轴像胶片进入片门一样从下向上滑入；
8. 其他旅程星尘层在最后 300ms 淡入。

如果用户快速切换旅程，旧动画必须在 120ms 内中止，新的镜头从当前位置开始。

### 14.7 路线、城市与载具特效

- **路线流光**：一条比主路线更亮的短线沿路径往返移动，只在静止状态出现；
- **载具拖尾**：飞机或列车移动时保留 8–12 个渐隐光点，长度不超过路线总长的 8%；
- **到达波纹**：载具抵达城市时，城市点出现两层扩散环，第二层延迟 120ms；
- **轨迹呼吸**：选中轨迹的透明度在一定范围内缓慢变化，未选中轨迹保持静止；
- **高铁摩擦光**：列车沿线移动时产生极短的细碎光点，不使用火花贴图；
- **归程收束**：到达常居城市时，路线颜色向暖白过渡，表示旅程结束；
- **重复路线**：使用不同高度和相位区分，流光相位也错开，避免混成一条。

### 14.8 地点篇章

- 地点卡片使用“照片先出现、文字后落下”的顺序；
- 主图显影从 1.04 倍缩放到 1 倍，同时清晰度从 8px 模糊回到 0；
- 最多四张辅图以 40ms 间隔扇形展开到拼图位置；
- 地点名称最后出现，并伴随一次细线从左至右展开；
- 鼠标移动只允许主图产生 2px 以内视差，辅图保持稳定；
- 没有照片时，使用地名首字、路线和星图纹理构成静态封面；
- 关闭地点卡片时先收起文字，再收起图片，避免整块面板同时消失。

### 14.9 照片回忆转场

打开照片回忆使用“光门”转场：

1. 地图整体亮度降至 35%，模糊增至 8px；
2. 主图位置先出现一条竖向暖光；
3. 暖光向两侧展开成完整照片；
4. 照片从 1.06 倍缩放到 1 倍，同时去除模糊；
5. 说明文字上浮 8px 并淡入；
6. 胶片条从画面底部滑入，当前缩略图放大到 1.15 倍。

普通上一张 / 下一张：

- 下一张：旧图向左退 12px，新图从右进 12px；
- 上一张：方向相反；
- 新旧图使用交叉淡化，不使用硬切；
- 柔光扫过方向跟随切换方向；
- 触屏滑动时根据滑动速度决定 180–420ms 的转场时长；
- 快速连续切换时，以最新目标为准，旧转场立即降级为淡化。

章节切换：

- 同一地点的照片切换只做普通转场；
- 进入新日期或新地点时插入章节卡；
- 章节卡使用左右分屏：日期在左、地点在右；
- 分屏合并后出现 80ms 的胶片颗粒闪断；
- 不播放闪白，不使用故障字效果。

缩放查看：

- 双击或双指放大时以点击点为中心；
- 最大 3 倍，松手不回弹；
- 放大时背景星点与文字透明度降低；
- 退出缩放后恢复到同一张照片与同一播放进度。

### 14.10 回忆星图特效

- 每个地点的照片簇从地图节点向外展开，形成小型星座；
- 同一地点的照片使用相同主题色，但亮度按时间递进；
- 鼠标移动产生 2–6px 的景深视差，卡片不做持续漂浮；
- 当前悬停照片放大到 1.08 倍，其他卡片轻微降亮；
- 点击照片时，卡片沿三段贝塞尔曲线飞向中央；
- 飞行过程中胶片条同步高亮目标照片；
- 关闭照片舞台时，照片飞回原星座位置；
- 只使用当前视口内的照片卡片，离开视口后停止动画。

### 14.11 环境特效

- 星点层：最多三层，速度不同，桌面端允许 4px 鼠标视差；
- 微尘层：只在照片回忆和旅程护照中启用，最多 20 个粒子；
- 光晕层：使用径向渐变，不使用实时阴影动画；
- 纹理层：静态胶片颗粒，不播放噪声视频；
- 路线光：只在空闲状态出现，不与转场同时运行；
- 所有环境特效在页面后台、拖动地球、缩放照片时暂停。

### 14.12 明确不使用的特效

- 屏幕抖动和随机震动；
- 无限脉冲和高频闪烁；
- 烟花、彩纸、爆炸粒子；
- 故障字、扫描线和赛博故障；
- 全屏持续动态噪点；
- 自动播放声音；
- 每张照片不同的随机滤镜；
- 为追求炫技而延长转场时间。

### 14.13 减少动态模式

当 `prefers-reduced-motion: reduce` 生效时：

- 强制切换到静谧档；
- 镜头切换改为即时定位；
- 路线不生长，直接显示完整轨迹；
- 删除路线流光、星点视差、微尘和封面倾斜；
- 照片不推近、不扫光，只保留 200ms 交叉淡化；
- 自动回忆默认不播放；
- 回忆星图改为静态分组网格。

## 15. 图片资产与性能

每个原图生成四级资产：

| 资产 | 目标宽度 | 用途 |
|---|---:|---|
| `thumb-sm` | 160px | 章节轴、胶片条、小卡片 |
| `thumb-md` | 640px | 旅程拼图、地点相册 |
| `preview` | 1600px | 回忆舞台常规浏览 |
| `original` | 原尺寸 | 用户主动缩放查看 |

同时生成 24–32px 的模糊占位图或等效低分辨率占位方案。

性能约束：

- 首屏只请求当前可见卡片所需的 `thumb-sm` / `thumb-md`；
- 回忆舞台同时挂载当前照片和下一张，上一张保留缓存；
- 预加载范围最多向前 1 张、向后 1 张；
- 相册按日期或事件分组，使用虚拟化或渐进渲染；
- 原图请求只在用户放大时发生；
- 地球交互期间暂停不必要的星尘和照片环境动效；
- 页面进入后台时暂停自动回忆与装饰动画。

动画性能预算：

- 桌面目标 60fps，移动端目标至少 45fps；短暂 30fps 不超过 200ms；
- 同一时刻最多一个主运动，并可叠加两个内容动画；环境动画保持低强度；
- 动画只修改 `transform`、`opacity` 和短时 `filter`；
- 全屏模糊仅用于场景转场，转场结束后移除；
- 装饰层使用独立合成层，结束后释放 `will-change`；
- 星点层最多三层，微尘最多 20 个粒子；
- 路线流光同一时刻只存在一条；
- 回忆星图只为视口内卡片创建 3D 上下文；
- 连续 2 秒低于目标帧率时自动降低一档动效强度，并在设置中保留用户原选择；
- 动画中止必须可恢复，不依赖定时器堆叠。

## 16. 回放

回放以当前旅程为单位：

1. 封面、标题和题记入场；
2. 镜头框住整段旅程；
3. 轨迹生长，载具沿当前交通段移动；
4. 抵达地点后点亮城市；
5. 停留展示地点主图和一句记忆；
6. 进入下一段交通；
7. 结束后显示收束卡：标题、日期、总里程、照片数。

控制项：

- 播放 / 暂停；
- 0.5x / 1x / 2x；
- 进度拖动；
- 跳过当前地点；
- 退出回放后回到当前旅程视图。

“全部旅行回放”不作为 v0.3 默认功能，后续可做成独立蒙太奇。

## 17. 响应式与移动端最低保障

本阶段不做完整移动端专项设计，但必须满足：

- 390px 宽度下无横向溢出；
- 旅程月台可横向滑动；
- 旅程护照变为底部抽屉；
- 地点篇章变为全高底部面板；
- 照片回忆的主图、说明、关闭、左右切换和胶片条均可操作；
- 所有触控目标至少 40px；
- 文字不因地球画布缩小而重叠。

---

## 18. 可访问性

- 所有旅程、地点、照片和回放控制均可键盘访问；
- 照片舞台打开时锁定焦点，关闭后焦点返回原按钮；
- 使用 `aria-live="polite"` 告知当前照片序号、日期和地点；
- 状态不能只靠颜色区分，需同时提供文字、形状或图标；
- 面包屑与当前范围提供可读的 `aria-label`；
- 自动回忆可暂停，并遵循系统减少动态设置；
- 主图上的文字遮罩保持足够对比度。

## 19. 边界与空状态

| 场景 | 处理 |
|---|---|
| 没有旅程 | 显示“建立第一段旅程”的引导与数据说明 |
| 没有封面照片 | 使用路线弧线、日期和主题色生成星图封面 |
| 没有照片 | 地点篇章仍可用，隐藏照片回忆入口 |
| 只有一张照片 | 隐藏胶片条、自动播放和进度条 |
| 只有一个地点 | 跳过路线生长，直接聚焦该地点 |
| 没有交通段 | 旅行统计显示 0 段，不显示空轨迹 |
| 旅程跨多年 | 旅行档案按开始日期归入年份，并显示完整日期范围 |
| 同城多次到访 | 按日期拆分为独立地点章节 |
| 照片缺少 EXIF | 使用数组顺序，并在内部状态标记“时间未知” |
| 照片文件缺失 | 开发模式报错，生产模式显示可恢复占位图 |
| 没有精选照片 | 隐藏精选切换，直接显示全部 |

## 20. 验收标准

1. 旅行档案只展示旅程级入口，不直接平铺全部交通与到访节点。
2. 常居城市以独立样式点亮，不生成旅行地点篇章，不计入目的地统计。
3. 两段不同旅程的路线、地点、统计、照片和回放完全隔离。
4. 同一城市跨旅程出现时，旅程视图只显示当前旅程的数据。
5. 旅行档案按年份组织，并优先展示最近旅程。
6. 每段旅程支持标题、题记、主题、封面和 0–5 张封面照片。
7. 地点篇章可进入照片回忆，精选与全部逻辑有明确回退。
8. 照片回忆支持键盘、触屏、自动播放、进度、暂停和减少动态模式。
9. 每段旅程数百张照片时，首屏不加载原图，滚动和切换保持流畅。
10. 390px 宽度下可完成进入旅程、查看地点和浏览照片。
11. 状态切换后不残留旧城市、旧回放或旧照片舞台。
12. 现有地球、地名反查、轨迹 hover、EXIF 归组和缩略图能力不回归。
13. 数据校验能识别无效旅程、越界日期、无效封面和常居城市误建到访。
14. 产品代码与文案中不写死用户举例的日期。
15. 默认电影感动效完整呈现路线生长、光门转场、章节卡和环境空气感。
16. 静谧 / 电影感 / 沉浸三档可即时切换并持久化，减少动态模式始终优先。
17. 回忆星图可展开、聚焦和返回照片舞台，移动端降级为分组瀑布流。
18. 页面空闲时没有无限高频动画；低帧率时能够自动降级且不影响浏览。

## 22. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 常居城市与旅行到访混淆 | 统计和旅程日期失真 | `homeCity` 单独点亮，禁止生活停留进入旅程 |
| 范围切换残留旧状态 | 错城市、错照片、错回放 | 使用状态切换矩阵并增加回归测试 |
| 精选无法由用户设置 | 精选入口成为空功能 | v0.3 使用数据策展，无精选时隐藏入口 |
| 小卡片加载大图 | 带宽浪费、滚动卡顿 | 使用 160 / 640 / 1600 / 原图四级资产 |
| 多年旅程塞入横向月台 | 档案难以浏览 | 年份分组、最近优先、全部旅程抽屉 |
| 动画与特效堆叠 | 眩晕、帧率下降、喧宾夺主 | 单主运动、内容动画上限、动效强度设置 |
| 回忆星图卡片过多 | 内存与渲染压力 | 只渲染视口内缩略图，移动端降级为瀑布流 |
| 低性能设备无法维持效果 | 操作迟滞 | 自动降档、减少粒子和 3D 层，保留核心转场 |
| 视觉特效先于结构改造 | 动效套在错误数据上 | 阶段 A 通过数据验收后再进入阶段 B |
